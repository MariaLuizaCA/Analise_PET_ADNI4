📌 README - Análise de Exames PET do ADNI com IA

📖 Sobre o Projeto

Este projeto faz parte de uma pesquisa acadêmica sobre o uso da Inteligência Artificial na análise de exames de imagem para o diagnóstico de Alzheimer. Nossa equipe foi responsável por trabalhar com exames PET (Tomografia por Emissão de Pósitrons) do banco de dados ADNI (Alzheimer's Disease Neuroimaging Initiative).

A principal tarefa foi acessar, organizar e processar os arquivos DICOM contidos no banco de dados, estruturando os metadados dos exames em tabelas para futuras análises.
